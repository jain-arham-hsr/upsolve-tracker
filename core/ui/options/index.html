Upsolve Tracker Settings

Upsolve Tracker reads your accounts to see which problems you have solved. Each platform needs its handle before you can add its contests — without one a contest would be stored unmarked, its solved problems would never clear, and it would look like the sync was merely slow.

Codeforces

Used to look up your accepted submissions.

Generate a key pair at codeforces.com/settings/api, then paste both halves below. The pair is stored in this browser only, is used to sign requests to codeforces.com, and is kept out of the JSON backup on purpose.

The secret half of the same key pair.

Checks the handle and key against Codeforces before you rely on them.

AtCoder

No key needed — the handle alone reads which problems you have solved.

CodeChef

No key needed. CodeChef answers for whoever is signed in at codechef.com, so this handle is what that session gets checked against — if they don't match, syncing stops rather than reading somebody else's solves.

Backup

Writes upsolve_tracker_backup.json to a folder you choose, refreshing it whenever your queue changes — adding a contest, removing one, or syncing. Import it from the Contests tab to restore.

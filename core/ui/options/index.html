Upsolve Tracker Settings

Upsolve Tracker reads your accounts to see which problems you have solved. Each platform needs its handle before you can add its contests — without one a contest would be stored unmarked, its solved problems would never clear, and it would look like the sync was merely slow.

Backup

Writes upsolve_tracker_backup.json to a folder you choose, refreshing it whenever your queue changes — adding a contest, removing one, or syncing. Import it from the Contests tab to restore.
